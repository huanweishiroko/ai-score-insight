# 学生成绩分析与可视化平台

## 项目简介
本项目是一个面向教师或班级管理人员的全栈学生成绩分析平台。它涵盖了“数据导入 -> 数据清洗与校验 -> 多数据集管理 -> 多维度动态查询 -> 统计指标计算 -> 可视化图表展示 -> AI 智能教学建议”的完整业务闭环。

## 技术栈
*   **后端**：Python 3.12、Flask、SQLite3
*   **前端**：HTML5、CSS3、原生 JavaScript、ECharts 5.4
*   **AI 集成**：DeepSeek API（大语言模型）
*   **开发环境**：`venv` 虚拟环境、`python-dotenv` 配置管理
*   **AI 辅助工具**：Cursor / DeepSeek 对话助手（详见“AI辅助开发过程”板块）

## 核心功能
1.  **多数据集管理**：支持新建“23级1班”、“23级2班”等不同数据集，数据物理隔离，互不覆盖，可通过下拉框自由切换查看。
2.  **CSV 智能导入与异常拦截**：支持导入 CSV 成绩文件。具备强大的数据校验能力（学号/姓名缺失、分数非数字、分数超出0-100范围等），能精准拦截错误行并返回警告，保证入库数据绝对干净。
3.  **动态组合查询**：支持按学号、姓名、科目进行单条件或组合查询，表格支持分页展示。
4.  **多维统计与可视化**：
    *   **统计卡片**：实时计算当前筛选条件下的平均分、最高分、最低分、及格率。
    *   **成绩区间分布柱状图**：直观展示不及格、及格、中等、良好、优秀五个区间的人数分布。
    *   **各科平均分对比图**：对比不同科目的整体表现。
    *   **成绩等级分布饼图**：展示各等级所占的比例。
5.  **AI 智能助教（亮点）**：
    *   **悬浮互动**：AI 形象常驻右下角，点击可触发气泡互动，根据时间段（早/中/晚/周末）展示不同问候。
    *   **多性格设定**：支持“可爱俏皮型”、“傲娇型”、“调皮型”、“社恐型”四种性格切换，不同性格下点击互动与 AI 分析语气完全不同。
    *   **情绪实时反馈**：点击互动时根据当前状态切换（疑惑/期待/开心/日常）表情；在分析成绩时，AI 会根据成绩好坏自动切换“开心”或“担忧”表情。
    *   **深入分析报告**：除了基础的一句话建议外，支持点击“深入分析”，让 AI 结合最高分、最低分、及格率等详细数据，生成 200 字左右的针对性教学建议报告。

## 启动方法
1.  **准备环境**（确保系统已安装 Python 3.10+）：
    bash
    # 创建虚拟环境
    python -m venv venv
    # 激活虚拟环境 (Windows)
    .\venv\Scripts\activate
    # 激活虚拟环境 (Mac/Linux)
    # source venv/bin/activate

2.  **安装依赖**：
    bash
    pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
   
3.  **配置 API Key**（根目录新建 `.env` 文件）：
    env
    DEEPSEEK_API_KEY=sk-你的实际DeepSeek_API_KEY
    
4.  **运行项目**：
    bash
    python app.py

5.  浏览器访问 `http://127.0.0.1:5000/` 即可使用。

## AI 辅助开发过程说明
本项目在开发过程中深度使用了 AI 工具辅助开发与排错，具体体现在以下几个方面：
1.  **数据库设计与优化**：在编写 SQLite 的 `ON CONFLICT(dataset_name, student_id, course) DO UPDATE` 时，通过向 AI 提问“如何在 SQLite 中实现存在则更新，不存在则插入的 Upsert 操作”，AI 给出了详细的 SQL 语法与占位符使用示例，并提示了唯一约束的重要性，大大减少了调试时间。
2.  **前端动画与交互优化**：在实现“AI 表情平滑切换”时遇到了图片加载卡顿的问题，通过向 AI 提问“CSS transition 切换 img src 时会闪烁，如何优化？”，AI 建议使用 `opacity` 配合 `transition` 进行淡出淡入，并建议对图片进行 `new Image()` 预加载，最终实现了极其丝滑的切换效果。
3.  **异常处理与健壮性**：在编写 CSV 解析逻辑时，通过 AI 辅助梳理了所有可能的异常场景（空文件、非数字、越界等），并借鉴了 AI 建议的“收集错误日志而非直接崩溃”的容错机制。
4.  **提示词工程**：在与 DeepSeek API 联调时，通过多次调整 Prompt，引入了“性格变量”和“情绪返回（mood）”，成功让 AI 根据成绩数据的好坏，以不同性格的口吻生成分析内容。

## 使用注意事项
*   首次导入数据前，建议点击输入框旁的“导入成绩”，输入数据集名称（如“23级1班”）。
*   若想重置所有数据，直接删除项目根目录下的 `scores.db` 文件并重启后端即可。
*   本系统推荐使用 Chrome 或 Edge 浏览器获得最佳体验。
